## 설계 요약

- **Site Factory** — 템플릿 기반 캠페인 랜딩 자동 생성
- **Inquiry Hub** — 잠재고객 수집·상태·배정
- **Attribution Layer** — UTM·행동 이벤트 추적
- **Control Tower** — 운영자 웹 콘솔

특정 외부 사이트 구조를 벤치마킹한 문서가 아닌, 업계 공통 패턴을 바탕으로 한 **독자 아키텍처**입니다.
